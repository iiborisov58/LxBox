## Problem

Чтобы собрать правило из готового rule-set'а, URL `.srs` ищут руками на
GitHub: открыть репозиторий, найти ветку с бинарниками, дойти до файла,
скопировать raw-ссылку. Без браузера на телефоне это почти невыполнимо, а
ошибиться легко: ветка `master` вместо `rule-set`, `.json` вместо `.srs`,
страница `blob/` вместо raw. И даже найдя файл, нельзя быстро понять, есть ли в
нём нужный домен.

## Decisions (владелец, 05.11.2026)

1. Форк личный — список источников живёт **в реестре контракта**, а не в
   коде. Код источников не знает. Как именно — см. «Contract» ниже: в зеркало
   реестра файл положить нельзя, он лежит черновиком реестра.
2. Состав — четыре источника:
   - `runetfreedom/russia-v2ray-rules-dat` @ `release` — `sing-box/rule-set-geosite`, `sing-box/rule-set-geoip`;
   - `SagerNet/sing-geosite` и `SagerNet/sing-geoip` @ `rule-set` — корень;
   - `MetaCubeX/meta-rules-dat` @ `sing` — `geo/geosite`, `geo/geoip`;
   - `legiz-ru/sb-rule-sets` @ `main` — корень.
3. Сразу с проверкой: скачать файл, показать состав и ответить «есть ли в нём
   домен / IP».

## Diagnosis — как получить список файлов (проверено 05.11.2026)

| Способ | runetfreedom | SagerNet ×2 | MetaCubeX | legiz-ru |
|---|---|---|---|---|
| jsDelivr `data.jsdelivr.com/v1/packages/gh/<repo>@<ref>?structure=flat` | **403** (пакет > 50 МБ) | 1681 / 237 | **403** | 10 |
| GitHub `git/trees/<ref>?recursive=1` | 2287, полный | 1996 | **27 МБ, truncated** (каталог `asn/`, 46 925 файлов) | 10 |
| GitHub `git/trees/<ref>:<dir>` (без рекурсии) | 2021 + 266 | 1996 / 237 | 2019 + 260, ~0,5 МБ | 9 |

Отсюда:

- **Основной путь — `git/trees/<ref>:<dir>` по каждому каталогу из реестра.**
  7 запросов на полное обновление; лимит без токена — 60 запросов в час с IP,
  поэтому список кешируется на `list_ttl_hours` (24 ч) и обновляется только по
  кнопке или по истечении срока при открытии поиска.
- **Запасной путь — jsDelivr flat-листинг**, отфильтрованный по каталогу (без
  вложенных). Он отвечает и при исчерпанном лимите GitHub, но только там, где
  реестр это разрешил (`jsdelivr_list: true`): для больших репозиториев он
  гарантированно 403, и пробовать его — лишний запрос.
- **Скачивание файла** работает через оба зеркала у всех четырёх: raw
  (`raw.githubusercontent.com/<repo>/<ref>/<path>`, по умолчанию) и
  `cdn.jsdelivr.net/gh/<repo>@<ref>/<path>` (лимит 50 МБ — на листинг, не на
  отдачу файла; проверено HEAD-запросом на MetaCubeX и runetfreedom).
  Зеркало выбирает пользователь; в правило пишется URL выбранного.
- **Сеть — только по явному действию** (§395): список запрашивается, когда
  пользователь открыл поиск, файл — когда нажал «Проверить». Ни таймеров, ни
  префетча.

## Contract — `rule_set_sources.json`

**Где лежит.** `app/assets/contract_draft/rule_set_sources.json`, а не
`assets/contract/registry/`. Зеркало реестра и вендоренная копия `app/contract/`
закоммичены и в CI сверяются `tool/check_contract_lock.dart`: копия — с
sha256 из `contract.lock`, зеркало — с копией файл-в-файл. Файл только в
зеркале — расхождение с копией; в обоих — копия не сходится с lock; пересчёт
lock руками — правка копии, которую правила запрещают (источник — репозиторий
лаунчера). Прецедент — `source_kinds.json`: он жил в `contract_draft/`, пока
не приехал контрактом 1.1.41 (§480 W6).

- Загрузчик (`RuleSetSources.load`) берёт `registry/rule_set_sources.json`,
  если тот есть в бандле, иначе черновик — порядок §480 у секций-мапперов.
- `rule_set_sources_test.dart`: файл ровно в одном месте. Приехал бампом —
  черновик снимается тем же коммитом.
- `mapper_sections_draft_test.dart` исключает файл по имени, как
  `source_kinds.json`: это не секция.
- Перенос в контракт: та же форма уходит в `contract/registry/` лаунчера, затем
  бамп (`sync_contract.sh --to <sha>`) и удаление черновика.

**Форма** — запись реестра (корень `_why` — только у черновика):

```json
{
  "v": 1,
  "rule_set_sources": {
    "list_ttl_hours": {"value": 24, "note": "…"},
    "sources": [
      {
        "id": "runetfreedom",
        "title": "runetfreedom — Russia",
        "repo": "runetfreedom/russia-v2ray-rules-dat",
        "ref": "release",
        "jsdelivr_list": false,
        "note": "…",
        "dirs": [
          {"path": "sing-box/rule-set-geosite", "kind": "geosite"},
          {"path": "sing-box/rule-set-geoip", "kind": "geoip"}
        ]
      }
    ]
  }
}
```

- `kind` ∈ `geosite` | `geoip` | `mixed` — фильтр в поиске, не семантика ядра.
- `path: ""` — корень ветки.
- Инвариант (тест): `id` уникальны; `repo` вида `owner/name`; у каждого
  источника ≥ 1 каталог; `kind` из набора; пути без ведущего/хвостового `/`.

## Behaviour

- **Вход.** В секции RULE-SET URL редактора правила — кнопка «Найти rule set»
  рядом с «Вставить». Открывает экран поиска.
- **Экран поиска.**
  - Строка поиска (подстрока имени файла, без регистра; порядок — точное имя,
    начало, вхождение; затем по длине и алфавиту). Показ ≤ 200 строк + счётчик.
  - Фильтры: источник (чипы, по умолчанию все) и вид (все / geosite / geoip).
  - Строка — имя файла, источник, вид, размер. Внизу — «Список от <время>» и
    «Обновить список». Ошибка источника видна, остальные источники работают.
- **Карточка файла** (тап по строке): путь, источник, размер, выбор зеркала
  (GitHub raw / jsDelivr), кнопки «Проверить файл» и «Использовать».
  - «Проверить файл» — качает (лимит 32 МБ), разбирает `readSrs` в изоляте,
    показывает состав: доменов, суффиксов, keyword, regex, IPv4/IPv6-диапазонов.
    Не `.srs` или битый — ошибка с текстом разбора.
  - После проверки — поле «Домен или IP»: ответ «найдено: суффикс
    `youtube.com`» / «IP в диапазоне 1.2.3.0–1.2.3.255» / «не найдено». Матчинг
    как в ядре: `domain` — точное; `domain_suffix` без точки — сам домен и
    поддомены, с точкой — только поддомены; `domain_keyword` — подстрока;
    `domain_regex` — RegExp (синтаксис Go RE2 в Dart почти совпадает; невалидный
    regex пропускается). Регистр и хвостовая точка домена нормализуются.
  - «Использовать» — URL выбранного зеркала добавляется в поле: пустое —
    заменяется, иначе дописывается новой строкой (дубликат не дописывается).
    Экран закрывается.
- **Кеш списка** — `rule_set_catalog.json` в каталоге данных приложения: по
  источнику — `fetched_at` и файлы. Не попадает в бэкап.

## Non-goals

- Не качаем файл в кеш правила при проверке: правило скачивает своё при ☁ /
  подъёме VPN (§053), как и раньше.
- Не ищем по содержимому всех файлов («в каком списке есть домен X») — это
  сотни мегабайт; проверка — в одном выбранном файле.
- Не добавляем GitHub-токен.
